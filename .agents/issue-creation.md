# Prismatic issue creation

Use the repo's issue forms and [labels](../.github/labels.json). [ISSUE_TRIAGE.md](../ISSUE_TRIAGE.md) owns classification: severity, Priority, Size, labels, titles, templates, and the leaf and container rules. The `ac-create-github-issue` skill owns the filing order and the post-create commands. [Independence groups](independence-groups.md) owns the group definition and record format; read it only when the triager returns groups.

An issue that removes or rewrites text, rules, or behavior lists what must be kept, as acceptance criteria an implementer can check. Implementation notes state the intent and the behavior affected. Quoted strings may show where to look, but never stand alone as a find-and-replace list.
